автодрома.

## Статус

Initial commit. Next.js skeleton и UI shell будут добавлены в последующих
фичах согласно документам в `Управление реализацией/` корневого репозитория
проекта.

## Связанные репозитории

- Backend monorepo: `../Autodrome`
- Документы и backlog: `Управление реализацией/` в корне проекта Autodrome.
